# Limitations

1. **Synthetic data** — Metrics prove the pipeline works, not that a real ops queue will improve.
2. **Simplified features** — Real prioritization needs domain fields, SLAs, and process constraints.
3. **No live serving** — No API, no queue integration, no monitoring dashboards in this folder.
4. **No fairness audit on real populations** — Required before any production HR/customer-impacting use.
5. **Not a client result** — Do not cite as third-party case study.
6. **Thresholds are demo defaults** — Client acceptance criteria are set per engagement.
