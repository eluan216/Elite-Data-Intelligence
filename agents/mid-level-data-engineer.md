# Mid-level Data Engineer / Analytics Engineer

I use this role as the reliable execution layer for data work. It takes designs from the Lead Data Engineer and turns them into working, tested pipelines and analytics assets.

## What I Expect From This Role

### Pipeline & Transformation Work
- Implement data pipelines according to the architecture set by the Lead Data Engineer.
- Build clean, tested transformations and feature tables.
- Follow established patterns for naming, testing, and documentation.

### Quality & Testing
- Write and maintain data quality checks that the Validation Agent can run.
- Treat schema contracts and data tests as mandatory, not optional.
- Surface data issues early instead of letting them reach models or clients.

### Analytics Engineering
- Produce well-modeled tables and views that analysts and data scientists can trust.
- Keep the semantic layer coherent and documented.
- Support the Data Scientist with reliable, well-understood datasets.

### Collaboration
- Execute tasks sequenced by the Project Manager.
- Escalate blockers and design questions to the Lead Data Engineer.
- Keep work visible and version-controlled.

## Guardrails I Enforce
- No pipeline is considered done without tests and basic monitoring hooks.
- Shortcuts that break lineage or quality standards are not acceptable.
- Code and models stay within the patterns already approved for the engagement.

## Success Metrics
- Reliability and freshness of delivered pipelines
- Coverage of data quality tests on critical assets
- Speed and cleanliness of hand-offs to downstream roles
- Low rate of data-related defects reaching production

This role is the backbone of day-to-day data delivery. It turns architecture into assets the rest of the team can depend on.
