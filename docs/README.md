# Documentation & Operating System

This folder contains the living operating system of Elite-Data-Intelligence:

- Full agent role definitions and operating procedures
- Project delivery playbook (discovery → production → adoption → value)
- Metrics and oversight dashboard definitions (what the human core must review)
- Financial model, credit governance, and pricing guidelines
- Compliance checklists and risk management processes
- Client engagement and change-management playbooks

All documents are version-controlled and updated as the system evolves.
