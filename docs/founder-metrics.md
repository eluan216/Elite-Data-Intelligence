# Founder oversight metrics

What I review while agents and the senior core execute. Keep this short and honest.

## Weekly

| Metric | Why it matters |
|--------|----------------|
| Open engagements by risk class | Capacity and exposure |
| Validation pass rate / open quality-gates | Delivery quality |
| Failure Analysis open > 7 days | Systemic or neglected defects |
| Discovery form volume → qualified calls | Commercial pipeline |
| Blocked work (access, scope, commercial) | Where I must intervene |

## Monthly

| Metric | Why it matters |
|--------|----------------|
| Closed engagements vs outcome vs original decision statement | Are we solving the right problems? |
| Rework after “PASS” | Validation rigor |
| Margin proxy (hours / complexity vs fee) | Sustainability toward $100k/mo |
| Claims on website vs implemented safeguards | Reputation risk |
| Agent definition drift | Roles still match reality |

## Red lines (escalate immediately)

- High/regulated work without human gate
- Client-facing claim that is not implemented
- Commercial commitment without founder approval
- Data leaving approved boundaries

## Cadence

- Skim open issues labeled `quality-gate` and `agent:failure-analysis` weekly
- Read discovery emails same day when possible
- Revisit this list when the operating model changes
