## 3. Approach

We follow our production decision-system pattern:

1. **Discover** — confirm decision, data access, risk, success metrics  
2. **Design** — feature/data path, method bar, validation criteria  
3. **Build** — model or workflow  
4. **Validate** — acceptance evidence before release  
5. **Operate** — hand-off notes, monitoring expectations, ownership

Artifacts are version-controlled. Material deliverables pass a validation gate with explicit PASS/FAIL criteria before client-facing release.
